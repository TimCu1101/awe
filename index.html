Google Apps Script (GAS) 後台後端程式碼

請將下方獨立撰寫的 App Script 貼入您的 Google 試算表擴充功能 (Apps Script) 中，即可自動處理「借用」與「歸還」動作，並回傳標準文字與狀態訊息。

Code.gs Apps Script JavaScript 
/**
 * 設備借銷與歸還管理系統 - Google Apps Script (GAS) 後端
 * 工作表名稱預設為：Equipment_List
 */

function doGet(e) {
  var equipmentId = e.parameter.id;
  var action = e.parameter.action || "borrow"; // 預設動作為借用 (borrow)，歸還為 (return)

  if (!equipmentId) {
    return ContentService.createTextOutput("請提供設備 ID，例如：?action=borrow&id=1001");
  }

  var ss = SpreadsheetApp.getActiveSpreadsheet();
  // 請確認您的試算表工作表名稱是 Equipment_List
  var sheet = ss.getSheetByName("Equipment_List");
  if (!sheet) {
    return ContentService.createTextOutput("錯誤：找不到名為 'Equipment_List' 的工作表！");
  }

  var data = sheet.getDataRange().getValues();

  for (var i = 1; i < data.length; i++) {
    // 比對 A 欄 (索引 0) 的設備編號
    if (String(data[i][0]).trim() === String(equipmentId).trim()) {
      
      var currentStatus = String(data[i][2]).trim(); // C 欄 (索引 2) 狀態
      var eqName = data[i][1];                      // B 欄 (索引 1) 名稱
      var eqBrand = data[i][4];                     // E 欄 (索引 4) 廠牌

      // =============== 動作 1: 設備歸還 (RETURN) ===============
      if (action === "return") {
        if (currentStatus === "借出中") {
          // 更新 C 欄 (在 getRange 中，C 欄是第 3 欄)
          sheet.getRange(i + 1, 3).setValue("可借用");
          return ContentService.createTextOutput(
            "歸還成功！\n" + eqBrand + " " + eqName + " 狀態已更新為「可借用」。"
          );
        } else {
          return ContentService.createTextOutput(
            "歸還失敗！該設備目前狀態為：" + currentStatus + "（非借出中狀態）"
          );
        }
      } 
      
      // =============== 動作 2: 設備借用 (BORROW) ===============
      else {
        if (currentStatus === "可借用") {
          // 更新 C 欄為 借出中
          sheet.getRange(i + 1, 3).setValue("借出中");
          return ContentService.createTextOutput(
            "借用成功！\n" + eqBrand + " " + eqName + " 狀態已更新為「借出中」。"
          );
        } else {
          return ContentService.createTextOutput(
            "借用失敗！該設備目前狀態為：" + currentStatus
          );
        }
      }

    }
  }

  return ContentService.createTextOutput("找不到設備編號：" + equipmentId);
}

1 Google 試算表欄位設定

請在 Google 試算表中建立一個分頁，名稱命名為 Equipment_List，並設定以下第 1 列標題：

  • A 欄: 設備 ID (例如 1001)
  • B 欄: 設備名稱 (例如 投影機)
  • C 欄: 狀態 (可借用 / 借出中)
  • D 欄: 保管人/備註
  • E 欄: 廠牌 (例如 Epson)

2 部署網頁應用程式 (Web App)

  1. 點擊試算表選單 擴充功能 ➔ Apps Script。
  2. 清除原本內容，貼上左側完整的程式碼並儲存。
  3. 點選右上角 部署 ➔ 新增部署。
  4. 種類選擇 「網頁應用程式」。
  5. 誰可以存取 (Who has access) 選擇：所有人 (Anyone)。
  6. 點擊部署並授權後，複製產生的 網頁應用程式 URL 貼回前台即可！
